# 决策记录（Decisions）

> 本目录沉淀本仓关键架构与实现取舍；更完整的 ADR 表在 `docs/architecture.md §3`。

| 编号 | 主题 | 关键取舍 |
|---|---|---|
| 001 | 继承 `Ruleset` 基类 | 规避 `ILegacyRuleset.LegacyID` 非 virtual 陷阱，换可被加载的正确性 |
| 002 | 共享核心源码编译并入 | 以编译期去重换部署正确性与单 dll 分发 |
| 003 | 精确锁版 + api-compat | 以固定版本换可复现构建，接受周级跟进成本 |
| 004 | 聚合官方 verifier | 借鉴思路重写实现，规避 GPL 传染同时保证可审计 |
| 005 | 三注入点收纳 | 以可落地性换交互自由度 |
| 006 | 五道质量门禁 | 以质量对齐替代 ranked 名义，门禁即完成定义 |
| 007 | 共享分析层、专属合成器 | 复用分析能力，按模式独立适配；ONNX 仅按需增强 |
| 008 | spectral-flux 自研节拍 | 以可控 DSP 换对不可靠 BASS_FX 的依赖 |
| 009 | IDistributionProvider 与语料安全 | 以可回退抽象换可用性，凭据仅经环境变量 |
| 010 | SR 闭环校准 | 有限轮次确定性迭代，边界失败由门禁兜底 |
