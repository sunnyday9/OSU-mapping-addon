# ADR-010 SR 闭环校准

- 日期：2026-08-21（M2–M6）
- 状态：已采纳

## 背景
需将生成谱面星数校准到用户目标 `±0.3★`（PLAN §3 门禁 G5）。

## 决策
各模式生成器内置 5 轮迭代校准：以 `TargetStarRating` 与实测 `*DifficultyCalculator` 星数的 delta，按 `multiplier *= (1 + delta / max(sr,0.5))` 在 `[0.5,2.0]`（osu 为 `[0.55,1.8]`×70px）范围内夹逼密度/间距；osu 用间距乘子、mania/taiko 用密度乘子，catch 复用同式。

## 后果
- 正：四模式统一收敛策略，可在有限轮次内贴近目标星数。
- 负：极端目标与短音频仍可能残差超容差，需由 G5 拦截不落盘。

## 取舍
以有限轮次的确定性迭代换可预期的校准成本，接受边界失败由门禁兜底。
