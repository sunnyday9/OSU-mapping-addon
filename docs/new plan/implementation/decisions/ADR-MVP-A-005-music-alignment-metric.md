# ADR-MVP-A-005 — 音乐对齐度量的定义（节奏网格 vs 整拍）

- **日期**：2026-08-23
- **状态**：已采纳
- **背景**：端到端管线初版 `music_alignment_score` 定义"对象是否落在整拍上（±2ms）"，实测只有 ~0.10——因为 1/8、1/16 细分的对象本就不在整拍上，该度量把合法细分全部判为"未对齐"。

## 决策

`musicAlignmentScore` 改为：**对象时间落在节奏网格（最小细分 1/16 拍，±2ms 容差）上的比例**。修正后 demo 实测 1.000。

## 理由

1. 1/16 是 mania-pattern-grammar-v0.1 允许的最小细分；落在 1/16 网格上的对象必然是合法量化输出；
2. "整拍对齐"度量对含 1/8/1/16 节奏的谱面有系统性偏差，不反映真实质量；
3. 网格度量同时验证了生成器的量化正确性（生成器按 beat 索引 × 细分生成，天然满足）。

## 影响

- `MappingIrPipeline.musicAlignmentScore()` 作为评估指标；生成器 `RhythmTimeline` 保证所有对象落在 1/16 网格；
- 未来若引入非量化节奏（swing），度量需再扩展（允许 swing 偏移量）。
